Idea 

Gaming Buddies 

“A more fun and creative way for gamers to connect with each other” 

 

 

 

 

 

1) What Will You Build? 

As technology has evolved, the gaming industry has introduced many changes when it comes to gamers connecting with each other. Whether it be cross platform functionality or apps like discord, the motive is quite clear in creating efficient ways to build friendships. As a result, we want to create a web application that takes a more creative/modern approach in creating these relationships known as “Gaming Buddies”. 

 

2) What The System Will Do? 

Gaming Buddies will allow users to upload/create an avatar on a live map of within their local area. This map will give users a familiar feeling of apps like “Snapchat” or “Wplace”. Going back, the user will have the ability to make customizations based on the tools we offer when creating their avatar. Users will have the ability to either hover or click on their fellow avatars to do the following actions: send a friend request, see status, see last game/current game playing, bio, etc. The map being live/dynamic means that all active users on the web app will see live changes in sync. One of these changes will include which user is active and not active based on the primary color of their fellow avatars.  

 

3) Why Is It Interesting? 

As developers, our objective for Gaming Buddies is to ensure a great experience. We define great as the following: An easy-to-use UI, eye attention details like avatars, and performance. If users are unable to navigate to basic/primary features like adding friends, they’re likely to delete the app. Additionally, we’ve emphasized that features like avatars give this creative feeling which separates it from other apps. Without this feature, our web app will lose its premise or foundation. Lastly, if our web app is unable to support most modern tech and smartphones, then this will give users another reason to delete the app. The reasons stated above are what makes our app stand out and which makes it interesting.  

 

4) High Level System Design?  

This project will be made up of three parts: the UI experience (Front-End), server-side(back-end) which acts as the bridge to server-side database. Front end is what the user can see and interact with, this will include avatar, avatar tools, buttons, etc. Back end is what’s occurring behind the scenes, essentially powering the interactive actions for the user and modifying, processing, validating user data. This will include the login page for user authentication/creation, dynamic map feature, and sending a friend request. Additionally, we will configure our friend requests to where they will be stored on a database. The database may also store the user’s BIO, status, and avatar info.

6) Usage Scenarios? 

Scenario 1: Johnny is a Wayne State student. He loves to play video games and really wants to see if there are any Wayne State students who also play video games. Gaming Buddies is the solution for this so he can look on the map and see people who play! 

Scenario 2: Kelly lives on campus. She has finished her exams and wants to play with her friend, Elma. Elma also lives on campus, but she isn’t too sure about if Elma is available or not. Gaming Buddies has a feature where it will show if Elma is online or not, and what game she is playing! 

Scenario 3: Tek loves Tekken 8. They really want to see if anyone else plays it, so they have more people to play with in person, rather than just play against randoms online. Gaming Buddies will show Tek who plays the game by looking at their profile! 

 

7) User Profiles? 

The users of Gaming Buddies will be anyone who plays games and wants to find new people to play with, connect with friends, and engage with others in a community of people who share the same interests.
